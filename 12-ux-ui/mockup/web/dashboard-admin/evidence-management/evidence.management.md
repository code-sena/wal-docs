## Objective
Allow the administrator to view, moderate (archive) and delete all system evidence generated by SOS alerts, with access to a player/viewer and filtering by type, status and user.
 
## Structure (top to bottom)
1. AdminLayout: Sidebar + Topbar
2. Title: "🎬 Evidence Management"
3. **Grid of 3 stat cards:** Total evidence | Videos | Photos + Audios
4. **Filters card:**
   - Input 🔍 "Search by user, alert..."
   - Type chips: All● / Video / Audio / Photo
   - Status chips: Active / Archived / Deleted
   - `app-period-badge` dropdown
5. **Evidence card (N files):**
   - Paginated table: # | Type | User | Alert | Size | Date | Status | Actions
   - Per-row actions: [▶️/🔍 View] [⬇️ Download] [📦 Archive] [🗑️ Delete]
   - Pagination
6. **View Evidence Modal:**
   - Video player / image viewer
   - Metadata: type, user, related alert, size, date
   - Download button
7. **Confirm Delete Modal (danger)**
## Components used
- `app-card` — stat cards, filters, table
- `app-chip` with `active: boolean` — type and status filters
- `app-period-badge` with `conDropdown: true` — period
- `app-modal` size `lg`, default — player/viewer
- `app-modal` size `sm`, danger — confirm delete
- `app-button` variant `danger`, size `sm` — delete in modal
- `app-spinner` size `sm`, inline — loading states
## States
- **loading:** Skeleton stat cards + table
- **ready:** Stat cards + paginated table
- **filtered:** Table updated by type, status or period
- **viewing:** Modal with player/viewer open
- **archiving:** Badge changes to "Archived"; row updates
- **deleting:** Danger modal active
- **no-data:** "There is no evidence registered in the system"
- **error:** Red toast
## Constraints
- **Mobile < 760px:** Stacked stat cards; table with horizontal scroll; collapsed sidebar
- **Tablet 760–1024px:** Stat cards in 2 cols; table without the size column
- **Desktop > 1024px:** Stat cards in 3 cols; full table
- **WCAG AA:** Stat cards with `role="status"`; table with `<caption>`; action buttons with descriptive `aria-label`; player modal with `aria-label`; danger modal with `aria-describedby`; chips with `role="checkbox"` and `aria-checked`; WCAG AA contrast
- **Dark mode:** Dark tokens active
